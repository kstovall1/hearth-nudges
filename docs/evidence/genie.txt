## When did opt-outs start rising?

status COMPLETED, 33 s

WITH weekly AS (
  SELECT
    `Week`,
    MEASURE(`Opt-outs`) AS `opt_outs`
  FROM `katie_febar_catalog`.`hearth_gold`.`reach_metrics`
  WHERE `Week` IS NOT NULL
  GROUP BY ALL
), bounded AS (
  SELECT
    `Week`,
    `opt_outs`,
    LAG(`opt_outs`) OVER (ORDER BY `Week` ASC) AS `prev_opt_outs`,
    `opt_outs` - LAG(`opt_outs`) OVER (ORDER BY `Week` ASC) AS `wow_change`,
    ROW_NUMBER() OVER (ORDER BY `Week` ASC) AS `rn_asc`,
    ROW_NUMBER() OVER (ORDER BY `Week` DESC) AS `rn_desc`
  FROM weekly
)
SELECT
  `Week`,
  `opt_outs`,
  `prev_opt_outs`,
  `wow_change`
FROM bounded
WHERE `rn_asc` > 1 AND `rn_desc` > 1
ORDER BY `Week` ASC

## How many members will we nudge tomorrow, and why are the rest held?

status COMPLETED, 26 s

sql:
WITH `latest_date` AS (
  SELECT MAX(`Decision Date`) AS `decision_date`
  FROM `katie_febar_catalog`.`hearth_gold`.`nudge_plan_metrics`
),
`sends` AS (
  SELECT
    p.`Decision Date` AS `Decision Date`,
    MEASURE(`Sends`) AS `members_to_nudge`
  FROM `katie_febar_catalog`.`hearth_gold`.`nudge_plan_metrics` AS p
  WHERE p.`Decision Date` = (SELECT `decision_date` FROM `latest_date`)
    AND p.`Action` = 'send'
  GROUP BY ALL
),
`holds` AS (
  SELECT
    p.`Decision Date` AS `Decision Date`,
    p.`Hold Reason` AS `Hold Reason`,
    MEASURE(`Holds`) AS `members_held`
  FROM `katie_febar_catalog`.`hearth_gold`.`nudge_plan_metrics` AS p
  WHERE p.`Decision Date` = (SELECT `decision_date` FROM `latest_date`)
    AND p.`Action` = 'hold'
    AND p.`Hold Reason` IS NOT NULL
  GROUP BY ALL
)
SELECT
  h.`Decision Date`,
  s.`members_to_nudge`,
  h.`Hold Reason`,
  h.`members_held`
FROM `holds` AS h
CROSS JOIN `sends` AS s
ORDER BY h.`members_held` DESC

what it did: You want to know how many members are planned to receive a nudge tomorrow and the reasons why the other members are being held back from receiving a nudge.

result (4 rows):

  2026-10-28 | 4449 | active | 11929
  2026-10-28 | 4449 | likely_back | 2226
  2026-10-28 | 4449 | not_worth_it | 2214

answer:
For **2026-10-28** (the latest decision date, used as tomorrow’s plan), **4,449 members** will be nudged. The rest are held mainly for **cooldown** (**13,547**), **active** (**11,929**), **likely_back** (**2,226**), and **not_worth_it** (**2,214**); **cooldown** is the largest hold reason and is about **6.1x** the size of the send group.
